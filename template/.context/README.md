# Context Index

Purpose: point a reader at the one context document a task needs.
Read when: the compact context alone does not cover the task at hand.
Update when: a focused document is added, renamed, or retired; `spctx sync-index` refreshes the generated list.

Open `AGENTS.md` and `.context/project.md` first. Turn to `.context/scientific-practice.md` when the task could change a result. Everything else is optional and listed below.

## Focused documents

for one or write it yourself. Choose a name that suits this project, open the
file with its own `Purpose`, `Read when`, and `Update when` lines, and put it in
`.context/` or `.context/active/` so it appears in the list below.
