# Glossary

Purpose: give each concept in the shipped text one word, and list the words that text avoids.
Read when: writing or reviewing any packaged file, skill, report line, or public document.
Update when: a concept is added, renamed, or retired, or real use shows a word misleading readers.

This glossary is for this repository. It does not ship: projects keep their own
vocabulary, and a shipped list of this product's terms would invite them into
project prose. `tests/test_scientist_facing_starter.py` reads the **Avoid** column and
fails when a packaged Markdown file uses one of those words outside inline code.
Each avoided entry is matched as a whole word, ignoring case.

| Term | Meaning | Avoid |
| --- | --- | --- |
| what later work depends on | A choice, input, or result that later work now assumes; the project lists these in `.context/project.md`. Listing one is when evidence comes due. | `relied on`, `relies on`, `rely on`, `load-bearing`, `frozen` |
| exploratory | The default state of any result nothing depends on yet. | `first look`, `first looks` |
| published | Leaving the project: a paper, poster, release, or handoff. The one moment the strict reproducibility standard applies. | `public or published` |
| context document | Any Markdown file under `.context/` other than the starter files. | `focused source`, `focused sources`, `context source`, `context sources` |
| instruction file | `AGENTS.md`, or the file the project's agents actually read instead. | `always-read file` |
| protected inputs | Data, reference material, calibrations, and curated decisions the work takes as given. | `protected material`, `protected files` |
| the user | The person directing the work. Projects may name people in their own sections. | `owner`, `owners`, `owns`, `responsible scientist`, `research lead`, `signs it off`, `authority` |
| packaged text | Text the package maintains and `spctx upgrade` replaces, such as the routing block and each skill body. | `managed region`, `managed regions` |
| the index | `.context/index.md`, generated by `spctx sync-index`. | `context inventory`, `list of context documents` |
| idea not yet adopted | A proposal kept in one place until the user adopts or drops it. | `proposal awaiting a decision`, `proposals awaiting a decision` |
| (none) | Gate and level-movement wording that trials turned into approval steps. | `promote`, `promoted`, `promotion`, `promoting`, `authoritative source`, `authoritative home`, `domain authority`, `without a decision`, `changed silently` |
